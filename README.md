VyanaSoul is a real-world, live and actively working production platform built for a spiritual consultancy, offering Akashic Readings, Pranic Healing, Lama Fera Healing, courses, and online consultations.

I built the full-stack platform using React/Vite and Supabase, implementing authentication, user dashboards, consultancy booking, backend APIs, course pages, blog, gallery, testimonials, FAQ, and an admin system.

The platform is deployed and actively usable, and was built around an actual client's business requirements rather than as a demo or college project. I also integrated a Telegram bot as requested by the client to support their workflow and improve communication/notifications.

This project gave me hands-on experience taking a real business requirement from idea to a complete, production-ready, working product, including frontend development, backend integration, authentication, database functionality, third-party integrations, deployment, and ongoing improvements.
